# Procedencia

- `README_archivo_cientifico_v13.md`: README del archivo científico v13 tal como se entregó. Sus comandos
  (`benchmark/recalcular.py`, `c50/recalcular.py`) fueron sustituidos por `scripts/gmm.py`, que ejecuta los mismos
  pasos en un directorio de ejecución separado.
- `c50_plan/`: planes fechados, adendas, diccionario de variables y registro de decisiones de los análisis C50.
  `PLAN_ADICIONAL_ORIGINAL_A-D_2026-10-01.txt` documenta un paquete de análisis adicional cuyos resultados (proyecciones
  a 2030, índice municipal, nuevas medidas de detección) **no** forman parte del artículo ni de este repositorio.
